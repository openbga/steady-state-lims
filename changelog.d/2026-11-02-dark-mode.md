The user menu has an **Appearance** choice of Light, Dark or System. It applies at once, follows the operating system when set to System, and is remembered for each account on this computer. Printing and report PDFs stay light.

## Technical notes

Adds the shell-only command `set_window_theme` for the window title bar. The choice is kept in the app's local storage for each account; no database change.
